# Contact Management System

A simple Contact Management System built with PHP and SQLite.

## Features

- Add new contacts
- Edit existing contacts
- Delete contacts
- Search contacts by name, phone, or email
- 10-digit phone number validation
- Email validation
- Duplicate phone number protection
- SQLite database storage
- Simple web interface

## Technologies Used

- PHP 8.5
- SQLite
- HTML5
- CSS3
- Git
- GitHub
- Termux

## How to Run

```bash
cd ~/contact_management_system
php -c ~/php-termux.ini -S 127.0.0.1:8080
